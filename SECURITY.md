# Security

Please report security problems through the [contact page](https://usernameinspector.com/contact/) (choose a topic that fits, and say it is a security report) instead of opening a public issue. Include what you found and how to reproduce it.

This server is read-only and stores nothing, so the most likely problems are abuse (excess requests) and incorrect results. Rate limits and a kill switch exist for the first; wrong results are best reported through the same contact page.
